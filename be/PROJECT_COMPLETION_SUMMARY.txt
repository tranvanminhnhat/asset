📊 DATABASE SCHEMA CHANGES

✅ NEW TABLES

PORTFOLIO_TRANSACTION (Append-Only)
  ├─ id (PK, AUTO_INCREMENT)
  ├─ portfolio_id (FK → PORTFOLIO)
  ├─ user_id (FK → USER)
  ├─ transaction_type (BUY, SELL, DIVIDEND, ADJUSTMENT)
  ├─ asset_type (string)
  ├─ quantity (DECIMAL 18,8)
  ├─ unit_price (DECIMAL 18,2)
  ├─ total_amount (DECIMAL 18,2)
  ├─ transaction_date (TIMESTAMP)
  ├─ notes (optional)
  ├─ reference_id (optional)
  ├─ created_at, updated_at
  └─ Indexes: (portfolio_id), (user_id), (transaction_date)

ASSET_PRICE (Historical)
  ├─ id (PK, AUTO_INCREMENT)
  ├─ asset_type (string)
  ├─ price (DECIMAL 18,4)
  ├─ price_date (TIMESTAMP)
  ├─ currency (optional)
  ├─ source (optional)
  ├─ created_at, updated_at
  └─ Unique Index: (asset_type, price_date)

ALLOCATION_STRATEGY (Future Use)
  ├─ id (PK, AUTO_INCREMENT)
  ├─ code (UNIQUE)
  ├─ name
  ├─ description
  ├─ status
  └─ created_at, updated_at

ALLOCATION_STRATEGY_DETAIL (Future Use)
  ├─ id (PK, AUTO_INCREMENT)
  ├─ strategy_id (FK → ALLOCATION_STRATEGY)
  ├─ asset_type
  ├─ allocation_percent
  ├─ display_order
  └─ created_at, updated_at

✅ EXISTING TABLES (ENHANCED)

PORTFOLIO (UPDATED)
  └─ Added FK constraint: user_id → USER(USER_ID)
  └─ userId type changed from Long to String
  └─ Added relationship mapping in entity

investment_plan (UPDATED)
  └─ Added FK constraint: user_id → USER(USER_ID)
  └─ Added relationship mapping in entity

investment_plan_allocation (UPDATED)
  └─ Added bidirectional mapping in entity
